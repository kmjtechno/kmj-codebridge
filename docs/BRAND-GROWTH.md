# KMJ CodeBridge Brand & Growth Playbook

## Positioning

**Category:** Secure AI-to-infrastructure coding bridge  
**One-line promise:** Connect your AI assistant to the computers and VPSs you already own—without opening inbound ports or handing it an unrestricted shell.  
**Tagline:** **Connect your systems. Build with AI.**

## Message pillars

1. **One bridge, many AI clients** — MCP-first, vendor-neutral architecture.
2. **Your machines stay yours** — outbound device connection and explicit project scope.
3. **Useful, not reckless** — bounded file tools, guarded writes and administrator-defined quality gates instead of arbitrary shell access.
4. **Open core, low-friction upgrade** — useful Community tier plus affordable hosted commercial plans.
5. **Built for proof** — CI-backed changes, durable job results and visible security boundaries.

## Launch content angles

- “Give ChatGPT or Claude access to the right project—not your whole server.”
- “No inbound VPS port. No self-hosted GitHub runner required.”
- “One MCP bridge for laptop + VPS + project-scoped coding.”
- “Open source first. Hosted convenience when you need it.”
- “From inspect → edit → test → verify, with explicit gates.”

## GitHub growth checklist

- Hero graphic above the fold.
- Clear 30-second explanation before implementation details.
- Copy-paste quick start.
- Security model visible near the top.
- Free tier and launch pricing discoverable without leaving GitHub.
- Real screenshots/GIF only after they show an actual working flow.
- Good-first-issue labels and reproducible issue templates.
- Release notes for every user-visible improvement.
- Demo clips optimized for X, LinkedIn, YouTube Shorts and Reddit developer communities.
- Ask for a star only after showing tangible value.

## Claims policy

Do not claim “most secure”, “fastest”, “world’s cheapest”, “production ready”, “zero trust”, certification, customer count or performance numbers unless the claim is supported by dated evidence. Prefer concrete claims such as “outbound-only device polling”, “project-scoped tools”, “Apache-2.0 source” and CI-backed test results.

## Visual system

- Base: near-black backgrounds, bright neutral text.
- Accent: KMJ red.
- Secondary: restrained cool gray.
- Avoid generic robot imagery and fake terminal screenshots.
- Show architecture, trust boundaries, devices and verified workflow.
- Keep KMJ TECHNO logo intact; do not redraw or distort it.
