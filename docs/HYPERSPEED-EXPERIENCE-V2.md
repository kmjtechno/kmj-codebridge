dual UI/UX roadmap in the Main Platform repository: device/project setup,

## Acceptance and constraints

Host-native icons, animations and permission UI are controlled by each client.
Record actual ChatGPT, Claude, Cursor and Zed compatibility, never assume it.
A supported MCP Apps card is complementary, not a native activity replacement.
Source implementation, CI, signed deployment and visual acceptance are separate.
No extra paid dependency, no local inference, no approval bypass, and no
production release until the owner changes the release hold.
