# KMJ CodeBridge Launch Playbook

The goal is sustainable discovery: stars, installs, contributors, trials and paid conversions generated by a product that developers can verify for themselves.

## Launch sequence

### 1. Repository readiness

- Keep main green on Linux and Windows.
- Keep the hero, value proposition and quick start above the fold.
- Make security boundaries obvious.
- Keep pricing and premium features visible but label non-live commercial items accurately.
- Use real screenshots or demos only.
- Maintain issue templates that prevent secret leakage and request reproducible reports.

### 2. Demo assets

Create short demonstrations around one outcome each:

- inspect an authorized project;
- edit one file with a hash/precondition guard;
- run a configured quality gate;
- show an outbound-only VPS connection;
- show one AI client switching between authorized devices.

Recommended clip structure:

1. 2 seconds — problem statement;
2. 6–12 seconds — actual CodeBridge workflow;
3. 2 seconds — proof/result;
4. 2 seconds — GitHub star / try-free CTA.

Never fabricate terminal output, benchmark numbers, customers or integrations.

### 3. Developer-community launch

Publish technically useful content instead of generic ads:

- GitHub release;
- X / LinkedIn engineering demo;
- relevant Reddit developer/MCP communities, following each community’s self-promotion rules;
- Hacker News “Show HN” when the hosted flow is genuinely usable end-to-end;
- dev.to / Hashnode architecture article;
- YouTube short demo plus a deeper security/architecture walkthrough.

The headline should state the concrete differentiator: project-scoped AI coding through an outbound agent, not unrestricted shell access.

### 4. Conversion funnel

Recommended sequence:

`GitHub → quick start → successful first device → 30-day Pro trial → value event → optional paid plan`

A “value event” should be measurable, for example:

- first authorized device connected;
- first successful project inspection;
- first guarded edit;
- first passing quality gate.

Do not optimize conversion by hiding cancellation, renewal price or trial terms.

## Suggested launch copy

### Short headline

**Give your AI access to the right project—not your whole server.**

### Short description

KMJ CodeBridge is an open-source MCP bridge for authorized laptops and VPSs. It provides project-scoped file tools, guarded edits and administrator-defined quality gates through an outbound device agent.

### Star CTA

**If CodeBridge solves a real development problem for you, star the repo so more developers can find it.**

## Metrics

Track only privacy-respecting product/business metrics needed to improve the funnel:

- GitHub stars and forks;
- README → setup click-through where measurable;
- successful first-device activation;
- successful first quality gate;
- trial activation;
- trial-to-paid conversion;
- churn;
- support issue category;
- failed enrollment rate.

Do not collect project source code or model conversation content merely for growth analytics.

## Launch blockers

Do not call the hosted product generally available until:

- fresh customer enrollment works;
- OAuth/account linking works;
- Main Platform billing + entitlement lifecycle works;
- customer dashboard scoping works;
- revocation/renewal paths are production-tested;
- public terms/privacy/refund pages match actual behavior;
- support and security contact paths are live.
