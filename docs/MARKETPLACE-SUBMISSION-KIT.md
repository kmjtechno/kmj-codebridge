## Review-safe test script

A publisher/reviewer account must be provisioned by an owner without
sharing access to real KMJ production repositories or customer data:

1. Sign in through the **real** OAuth login.
2. List only the demo account's enrolled device and test project.
3. Read one public demonstration file under the approved project root.
4. Test a denied file path outside the project; require access denial.
5. With explicit demo write permission, perform one hash-guarded file
   update and run a preconfigured harmless quality gate.
6. Revoke the demo device; prove subsequent actions are denied.

Record tool names, actual outputs and permissions from the deployed
build. Never create fake data to bypass the review portal.

  fulfills the order as an entitlement and product-specific license

  *before* promising immediate delivery or an SLA.

  GST status or automated checkout without production verification.
